# 0.1.0a2 development preview

This revision prepares four independent security decision skills, four portable Markdown profiles, and an optional record-only stdio MCP server. It is not a published release. The existing 0.1.0a1 draft and assets remain pinned to their earlier source revision.

Added: Attack Path Rehearsal, Detection Replay Lab, Security Regression Board, and Security Skill Router. Total: 24 skills and 14 profiles. Python 3.11+, standard-library runtime, no API keys. MCP exposes only these four bounded record functions, without arbitrary file, shell, network, sampling, or installation tools.

The reference library was inventoried at a pinned source revision and selected workflows reviewed in depth. No reference skill, code, mapping dataset, artwork, or template was imported. [Review and product decisions](../research/reference-review.md).

[Security decision examples](../assurance-workflows.md) include graph uncertainty, a detection missed after a field rename, excluded comparisons, and deferred routing work. The synthetic benchmark compares our exact-match replay to an openly labeled toy baseline. It is not a competitor, model, or real-world security benchmark. Selected entrypoint bytes are not model tokens or cost savings.

The four additions are declaration-based and remain PARTIAL. Their limits include incomplete graphs, unverified evidence, exact-match-only detection, untrusted labels, a closed routing vocabulary, and unverified native assistant integration. [MCP data boundary](../mcp.md): results flow to the invoking host, whose provider policy is outside this helper's control.

There is no CI pipeline or required CI check. Run local verification from CONTRIBUTING.md and .specs/evidence.md. Human review remains required for protected main. No package, tag, or release is published by these changes.

Full standalone skill bundles live in the source checkout. Wheel/source distributions package the Python CLI and MCP runtime, not the complete skill library. No global skill configuration or running service is changed automatically.
