# Security Agent Skills 0.1.0a1

Preview release notes. This is an alpha prerelease, not a stable security product. Publication follows the required independent review; preparing these notes does not publish a release.

## Included

- Twenty portable skills: fifteen security-review workflows and five internal-operation workflows.
- Ten Markdown role profiles. Profiles do not register native agents or grant permissions.
- Python 3.11+ standard-library helpers with bounded inputs, consistent report-v1 JSON, explicit unknowns, stable finding IDs, and optional compact console output.
- A preview-first installer for project and personal skill discovery layouts in Claude Code, Codex, Cursor, and supported Copilot surfaces. Existing installations are never overwritten.
- Original security artwork, a synthetic CLI GIF, static/text alternatives, example operation records, input schemas, and documented capabilities.

The sandbox plan helper rejects non-array command input and preserves valid argv without executing it.

## No CI dependency

GitHub Actions is disabled for the repository. No workflow or required pipeline status remains. Verification uses the local commands in [CONTRIBUTING.md](../../CONTRIBUTING.md). Main's independent review and other branch protections remain in force.

## Verification scope

The local suite exercises all twenty helpers across four temporary host layouts, including 80 installed bundles. Source/bundle consistency, input validation, no-overwrite behavior, report privacy, synthetic boundaries, authority declarations, and retry-state handling are covered. Build and offline wheel smoke are local checks, not proof of complete security coverage.

Three representative skills were explicitly loaded and exercised in the current Codex desktop session on Windows. This does not establish automatic skill discovery or universal assistant compatibility. See [compatibility evidence](../compatibility.md) and the [release assessment](../release-readiness.md) for actual check results.

## Known limits

- Latest macOS execution and real Claude Code, Cursor, and Copilot sessions remain unverified. The earlier macOS jobs were abandoned because hosted runners were unavailable, not marked passed.
- Static scanners emit incomplete review leads, including possible false positives. They cannot prove safety, exploitability, absence of malware, or all outbound data flows.
- Internal-operation helpers validate supplied declarations. They do not verify approval authenticity, evidence truth, freshness, or actual external effects.
- AppSec and sandbox helpers only validate or generate plans. No exploitation, DDoS execution, packet capture, or runtime sandbox attestation is provided.
- Export scrubbing is best effort. Filenames, scope paths, and symbolic reference IDs can be sensitive. Review before sharing.
- Filesystem operations do not defeat every concurrent replacement race. Use trusted, stable local copies. OS network shares and hosted-assistant data handling are outside the no-direct-client check.
- The existing report serialization benchmark is synthetic. No universal token, billing, model quality, or checkpoint savings claim is made.

## Install the correct artifact

The full-kit ZIP contains skills/, agents/, catalog.json, schemas/, and scripts/install_skills.py. Verify its SHA-256 against SHA256SUMS, extract it, and use the preview-first installer. The Python wheel and source distribution install the CLI; they are not the full twenty-skill kit.

Checksums detect byte changes against the supplied checksum file; they do not authenticate the publisher. This release has no signing or external attestation claim. Runtime helpers have no third-party Python dependencies. The kit includes the MIT license.
