# 0.1.0a3 development preview

Adds two attributed offline adaptations: Email Header Triage and HTTP Header Snapshot Review. Total: 26 skills and 16 portable profiles. The optional MCP interface remains four tools. No release, package, or tag is published by this change.

Selected pure functions are reused under Apache-2.0 from mukul975/Anthropic-Cybersecurity-Skills at a pinned revision. Source hashes, original authorship, modification notices, and both licenses accompany standalone bundles and built distributions. Original Fliorcie code remains MIT. [Notices](../../THIRD_PARTY_NOTICES.md) and [scope](../adapted-skills.md).

Adapters accept bounded local header records, suppress raw values, retain unknown authentication and transport claims, and return PARTIAL. No DNS/HTTP request, attachment processing, live sender verification, or complete browser-policy evaluation is implemented. Native assistant integration remains unverified. CI stays disabled and independent protected-main review remains required.

The earlier 0.1.0a1 draft and assets remain unchanged. The two new skills are limited adaptations of selected helpers, not complete upstream script imports or wholly original work.
