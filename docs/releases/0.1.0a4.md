# 0.1.0a4 development preview

Renames the two attributed header skills to Mail Auth Review (mail-auth-review) and Web Header Review (web-header-review). Existing email-headers and http-headers commands and record schemas are retained. Adds header-review to combine either or both supplied records.

Header commands default to a distinct brief schema, with three visible findings, full counts, explicit omissions, all observations, and unchanged PARTIAL status. --view full restores the full console schema; --output saves unabridged evidence to a new file. Existing installs are not silently renamed or overwritten.

Synthetic local output measurements show 33.43% fewer cl100k_base tokens for mail and 31.07% for web without omitting findings. Combined presentation saves 27.29% with all findings, or 44.01% with the default three-finding cap and explicit omissions. These are serialization measurements, not platform billing or quality claims. [Workflow and benchmark](../header-review-workflow.md).

All original attribution and mixed MIT/Apache-2.0 licensing remain. No new network client, MCP tools, host configuration, global installation, CI pipeline, release publication, or tag is added. Native assistant integration and security coverage limits remain documented.
