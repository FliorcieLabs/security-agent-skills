# Translated introductions

The English README is the complete catalog and reference entry point. The Japanese, Simplified Chinese, Korean, Hindi, and Spanish READMEs are concise introductions covering scope, setup, compatibility limits, privacy, and the public project suite. They do not translate executable instructions, schemas, identifiers, or the complete documentation.

These translations were prepared with AI assistance. Independent native-speaker review has not been recorded. Corrections are welcome through the repository's normal contribution process. A language link is not a claim of localized runtime output or model-session verification.

When the catalog or supported behavior changes, update every introduction together. Preserve exact command names, Python requirements, preview status, PARTIAL exit behavior, the distinction between declared evidence and observed results, host data-policy limits, and licensing. Keep relative links valid and do not translate filenames or command flags.

Artwork contains English text. Each translated introduction supplies equivalent alt text and surrounding explanations. The renderer's counts must match the catalog; see [artwork provenance](assets/security/README.md).
