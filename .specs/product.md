# Product boundary

Forty-one portable skills for local security review and internal agent operations, plus thirty-one portable Markdown agent profiles. All use one compact report contract and optional standard-library helpers. Static checks preserve unknowns. Internal-operation helpers validate supplied records; they do not orchestrate agents, grant tool authority, retry actions, or attest that record claims are true. No telemetry, hosted backend, automatic publishing, or credential handling. Active app attacks and distributed denial-of-service are outside the product.

Development preview 0.1.0a2 adds declared-graph rehearsal, exact-match detection replay, paired regression metrics, bounded skill selection, and optional record-only stdio MCP. MCP transports records to the invoking host; hosted client data handling remains outside the helper boundary.

Development preview 0.1.0a3 includes two Apache-2.0-attributed offline header adaptations. Original Fliorcie code remains MIT; bundled adapted modules retain their Apache terms and notices.

Development preview 0.1.0a4 renames the two header skills and adds brief presentation plus a combined local header-review workflow. Compact output has its own schema and preserves observations, counts, unknowns, and full-evidence export.

Fifteen domain additions provide evidence-guided Markdown review and strict declared-control checks, not scanners or live validation engines.
