# Product boundary

Twenty portable skills for local security review and internal agent operations, plus ten portable Markdown agent profiles. All use one compact report contract and optional standard-library helpers. Static checks preserve unknowns. Internal-operation helpers validate supplied records; they do not orchestrate agents, grant tool authority, retry actions, or attest that record claims are true. No telemetry, hosted backend, automatic publishing, or credential handling. Active app attacks and distributed denial-of-service are outside the product.
